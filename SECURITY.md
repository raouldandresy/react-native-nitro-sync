# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities. Report privately through the GitHub Security tab using **Report a vulnerability**, or contact the maintainers at `security@nitro-sync.example`.

Include the affected version, platform, reproduction steps, impact, and a proposed mitigation when available. We will acknowledge reports within seven days and coordinate disclosure after a fix is available.

The repository should have GitHub Dependabot alerts, security updates, and secret scanning enabled in **Settings > Code security and analysis**.
